Privacy policy

Last updated: 28 October 2026

Who uses Inbox Filter Ping

Inbox Filter Ping is a personal tool used only by its owner, on the owner's own Gmail account. It is not offered to anyone else.

What data it accesses

With the owner's permission (Google OAuth, read-only scope), Inbox Filter Ping reads the sender, subject, date and content of new emails in the owner's inbox, to detect specific notification emails.

How the data is used

The data is used only to detect and display those notifications to the owner. Inbox Filter Ping does not send, delete or modify any email.

Storage and sharing

Data is processed on the owner's own server and is not sold, shared with or transferred to any third party. Logs are kept only as long as the owner needs them.

Google user data

Inbox Filter Ping's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
